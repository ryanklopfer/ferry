# Test corpus

## `synthetic/` — in git

Generated by `bun run corpus:generate` from `scripts/corpus/data.ts`. Every person, provider, identifier and member number is invented: NPIs pass the check digit but are not registered to anyone we looked up, EINs use the never-issued `00-` prefix, the one SSN uses the invalid `000` area, phones are in the fictional `555-01xx` block.

`labels.json` is the ground truth the scoring harness (slice 4) compares extraction against. To add a case, add a spec to `data.ts` and regenerate; the label and the document come from the same object, so they cannot drift. The generator throws if a description would not fit its column, because a truncated print would no longer match its label.

| Id | Format | What it stresses |
|---|---|---|
| sb-01 | text PDF | clean single line, solo provider |
| sb-02 | text PDF | four dates of service, long-form dates |
| sb-03 | text PDF | telehealth: modifier 95, POS 10, ISO dates, "Provider NPI" / "TIN" labels |
| sb-04 | text PDF | psychological testing with units (96130/96131/96136/96137), two diagnoses, pointers, minor patient |
| sb-05 | text PDF | psychiatry E/M + add-on psychotherapy, per-line diagnosis pointers |
| sb-06 | text PDF | group practice: billing NPI ≠ rendering NPI, two modifiers, mixed POS |
| sb-07 | text PDF | Tax ID is an SSN, family therapy, Z-code |
| sb-08 | photo JPG | no NPI anywhere; skewed phone photo |
| sb-09 | photo JPG | handwritten form |
| sb-10 | image PDF | fax quality, two pages, six dates, partial payment |
| card-01…05 | photo JPG ×2 | PPO/POS cards, front and back: Aetna, Cigna, UnitedHealthcare, Anthem Blue Cross, BCBS of Texas |
| card-06…08 | photo JPG ×2 | gated plans: Kaiser HMO, Medicaid, Medicare |

Card member data is synthetic. For slice 7, replace it in `data.ts` with Stedi's documented mock subscribers and regenerate, so a card photo drives a real mock 271.

`audio/` comes from `bun run corpus:audio` (`scripts/corpus/audio.ts`): `tone-10s.wav` (10 s of 440 Hz, 16 kHz mono) feeds Chromium's fake mic in `e2e/mic-spike.spec.ts`, and `speech-synthetic.wav` is macOS `say` reading invented lines, for playing at a phone during the Gate A run (`docs/plans/capture-device-matrix.md`). No real voice is ever recorded or kept.

Rasterizing uses macOS Quick Look (`qlmanage`), so the generator runs on a Mac only. Photo noise is random, so regenerated JPGs differ byte-for-byte; regenerate deliberately, not in CI.

## `real/` — never in git

De-identified real superbills, cards and EOBs from the founder's network. De-identify **before** the file reaches this machine: name, DOB, address, member ID and any account number blacked out on the image itself, not covered by an annotation layer. Put a `labels.json` beside them in the same shape as the synthetic one. This folder is gitignored and must only ever be sent to an LLM endpoint covered by a BAA.
