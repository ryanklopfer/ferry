# Lessons

## 2026-09-17 — Check the vendor's docs before asking the founder what a vendor term means

I listed "clarify Stedi's CMS-1500 validator" as a founder question (F12). Two fetches of Stedi's docs answered it: the term maps to Stedi's claim edits. The founder's guess was different from what the docs say, so asking cost a round trip and nearly put a wrong definition into the spec.

Rule: when a term in a planning doc names a vendor feature, read the vendor's documentation first. Ask the founder only what the docs cannot answer: intent, priority, or business decisions.
